Decide the product boundary for customer-cloud mode.

**Question:** Is customer-cloud mode a first-class product path or an advanced/self-managed path?

**Context:** Sun can target customer-owned infrastructure through environment targets, Terraform modules, and GitOps emit. The product bias says Sun-hosted should become the primary hosted path while customer-cloud remains possible without complicating the default experience.

**Options:**

1. First-class path with polished onboarding and support.
2. Advanced path with clear substrate contract and best-effort tooling.
3. Internal/reference path only.

**Decision criteria:**

- Target customer expectations.
- Support burden.
- Documentation complexity.
- Whether `sun cloud init` should ever exist.

**Acceptance criteria:**

- A written decision defines the support level.
- Docs use matching language consistently.
- Any needed follow-up tickets are created for CLI, docs, or Terraform work.

**Decision:**

Customer-cloud mode is an advanced/self-managed path, not the default first-class
product path.

Sun-hosted is the first-class product experience for users who want the simplest
path from project to production. Customer-cloud remains supported as an
escape-hatch path for teams with compliance, procurement, infrastructure, or
control requirements that make hosted unsuitable.

This does not mean customer-cloud should be hostile or undocumented. It should
have a clear substrate contract, working Terraform/reference modules, GitOps
emit support, and honest docs. It should not drive the default UX or force
hosted users to learn cloud substrate concepts.

**Implications:**

- Product onboarding optimizes for Sun-hosted.
- Customer-cloud docs are explicit that the user owns the substrate.
- `sun deploy --emit-to` and the self-hosted substrate contract remain important.
- A broad `sun cloud init` command should not be prioritized until customer-cloud
  demand proves it is worth productizing.
- Shared abstractions such as deployment plans, secrets, and release diagnostics
  should work across modes, but hosted remains the paved road.
