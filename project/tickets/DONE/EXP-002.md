`sun dev run` command is missing.

**Description:** `sun dev run` does not exist. `sun dev` has only `up`, `down`, `status`. After `sun dev up` starts infrastructure, there is no Sun command to run workspace services locally.

**Impact:** Engineers must either deploy to k3d via `sun up` (overkill for local iteration) or invoke `dune exec` per service with manual env var injection.

**Remediation:** Implement `sun dev run` to start all workspace binaries in parallel via `dune exec`, injecting dev env vars (KAFKA_BROKERS, POSTGRES_URL, LOKI_URL, etc.), and tail combined stdout/stderr with per-service prefixes.
