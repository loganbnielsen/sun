TUTORIAL.md and README Prerequisites missing libpq-dev and libpq5 system packages.

**Depends on:** None.

**Description:** TUTORIAL.md Prerequisites (line 27) and README Requirements (lines 458–459) list only `librdkafka-dev`. The generated workspace scaffold includes `caqti-driver-postgresql` as a build dependency (in `app/payments/charge_svc/bin/dune` and `app/comms/notify_worker/bin/dune`). This requires `libpq-dev` at build time and `libpq5` at runtime. `docs/dogfood/DOGFOOD.md` (the internal runbook) lists both packages, but neither the user-facing TUTORIAL nor the README does.

**Impact:** An engineer following TUTORIAL.md or README will run `dune build` after scaffolding and encounter a build failure. The C library linker error ("Cannot find C library: pq" or similar) is not self-explanatory to engineers unfamiliar with OCaml C stubs. They must discover `libpq-dev` through trial and error or by reading DOGFOOD.md, which is not linked from either guide.

**Remediation:**
1. In TUTORIAL.md Prerequisites section (line 27), change:
   `librdkafka-dev` (`sudo apt-get install -y librdkafka-dev`)
   to:
   `librdkafka-dev`, `libpq-dev`, `libpq5` (`sudo apt-get install -y librdkafka-dev libpq-dev libpq5`)
2. In README.md Requirements section (line 459), update the `librdkafka-dev` line to also mention `libpq-dev` and `libpq5`.
