TUTORIAL.md CLI reference table is missing sun rollback, sun logs, and sun secret commands.

**Depends on:** None.

**Description:** The TUTORIAL.md CLI reference table (lines 399–416) lists only scaffold, dev, deploy, status, and migrate commands. It does not include `sun rollback`, `sun logs`, or `sun secret`. All three commands are implemented and documented in README.md but absent from the TUTORIAL, which is the primary onboarding document.

**Impact:** An engineer who onboarded using the TUTORIAL will not discover `sun rollback` after a bad deploy, will use `kubectl logs` instead of `sun logs`, and will not know `sun secret` exists. The TUTORIAL is where new engineers spend their first hour — missing commands there become unknown-unknowns.

**Remediation:** Add the following entries to the CLI reference table in TUTORIAL.md (after the `sun migrate` entries):

```
sun rollback [domain/service]                       roll back last deploy for one or all services
sun logs <service> [--no-follow] [--tail=N]         stream logs from a deployed service
sun secret set <KEY> --env <ENV> --value <VAL>      create or update a secret
sun secret list --env <ENV>                         list secret keys (values never printed)
sun secret delete <KEY> --env <ENV>                 delete a secret
```

Also add brief prose descriptions for `sun rollback` and `sun logs` in TUTORIAL.md Day-2 context (can be one sentence each, linking to README for full detail).
