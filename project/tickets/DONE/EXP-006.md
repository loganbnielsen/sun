`sun up` vs `sun deploy` split is unexplained and confusing.

**Description:** Two deploy commands exist with overlapping names and distinct semantics: `sun up` builds images and deploys locally; `sun deploy` skips the build and is CI-only. The UX promise uses `sun deploy` but running it locally without pre-built images silently fails or errors confusingly.

**Impact:** An engineer following the promise `sun deploy → I can ship` runs `sun deploy` locally and either gets an error or deploys a stale image. The distinction is never explained in user-facing docs.

**Remediation:** Add callout in README and TUTORIAL distinguishing the two commands. Update `cmd_deploy.ml` doc string to say "CI mode" and improve the no-images error message.
