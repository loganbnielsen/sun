Document `--registry` / `CLOUD_REGISTRY` requirement for `sun cloud deploy`

**Depends on:** None.

**Description:** `docs/guides/TUTORIAL.md` shows `sun cloud deploy --environment production` without `--registry`. After CLOUD-005, a non-dry-run `sun cloud deploy` requires `--registry <URL>` or `CLOUD_REGISTRY` in the environment or it exits 1 with an error. The tutorial does not mention this requirement.

**Impact:** A user enabling the hosted deploy path cannot follow the tutorial example verbatim — the command fails immediately. They must read the CLI help to discover the missing flag.

**Remediation:**
1. Update the "Hosted control-plane release history" section in `docs/guides/TUTORIAL.md` to include `--registry` in the `sun cloud deploy` example (or show `export CLOUD_REGISTRY=...` before the command).
2. Add a one-sentence explanation of what the registry URL refers to (the container registry images are pushed to).
3. Update `README.md` — the Status table row "Sun-hosted executor: Experimental mock boundary" is now outdated; update it to reflect the build-and-push pipeline from CLOUD-005.
