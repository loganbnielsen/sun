Generated workspace README instructs manual bash scripts instead of `sun` commands.

**Description:** The README template in `cli/sun/lib/sun_cli_cmd_new.ml` (`tpl_readme`, line 77) has a "Run locally" section that says `bash <path-to-sun>/platform/local/scripts/ensure-broker.sh`. This requires knowing the Sun repo location on disk and contradicts the `sun dev up` instructions elsewhere in the template.

**Impact:** An engineer reading their generated `README.md` finds contradictory instructions. Following the first section requires out-of-repo knowledge.

**Remediation:** Remove the bash-script "Run locally" section from `tpl_readme`. Replace with `sun dev up` + `sun dev run`. Add `sun dev run` to the CLI commands table. Depends on EXP-002.
