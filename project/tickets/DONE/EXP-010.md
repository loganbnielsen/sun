TUTORIAL.md states incorrect generated file count and incomplete scaffold tree listing.

**Depends on:** None.

**Description:** TUTORIAL.md line 80 says "This generates 19 files." The `new_workspace` function in `cli/sun/lib/sun_cli_cmd_new.ml` contains 22 `write` calls, and the CLI prints "Done. 21 files generated." The TUTORIAL's tree listing (lines 81–113) omits three files that are actually created: `.ocamlformat`, `.github/workflows/deploy.yml`, and `.github/workflows/sun-ci.yml`.

**Impact:** Minor trust erosion. An engineer who runs `sun new workspace` and sees "21 files generated" will notice the mismatch with the guide's claim of 19. The omitted CI workflow files are important — engineers setting up GitHub Actions will not know they were generated.

**Remediation:** In TUTORIAL.md:
1. Update line 80 from "This generates 19 files" to "This generates 21 files".
2. Add the three omitted files to the tree listing with brief descriptions:
   - `.ocamlformat` — OCaml formatter config (profile = default, version = 0.27.0)
   - `.github/workflows/deploy.yml` — Basic CI deploy workflow (direct cluster push)
   - `.github/workflows/sun-ci.yml` — Full Sun CI pipeline (build → images → GitOps manifests)
