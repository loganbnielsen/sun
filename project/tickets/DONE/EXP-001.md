No binary distribution; full OCaml toolchain required to install `sun`.

**Description:** There is no pre-built `sun` binary. Getting the CLI requires installing `opam`, setting up OCaml 5.4.1, installing `librdkafka-dev`, running `opam install . --deps-only`, and running `dune build cli/`. This is a multi-step toolchain setup entirely unrelated to using the platform.

**Impact:** A startup engineer who wants to evaluate Sun must become an OCaml environment expert before writing a single line of business logic. The install friction alone breaks the "zero to running service" promise.

**Remediation:** Publish prebuilt binaries via GitHub Releases. Add a one-liner install to the README: `curl -sSL .../sun-linux-x86_64 -o /usr/local/bin/sun && chmod +x /usr/local/bin/sun`. Keep build-from-source as a contributor path.
