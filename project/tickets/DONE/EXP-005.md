`sun status` port-forward hint broken after AUDIT-004; service access still requires manual kubectl.

**Description:** `cmd_status.ml` queries for `NodePort` services to print the port-forward hint, but AUDIT-004 changed all generated services to `ClusterIP`. The hint is never printed. After `sun up`, reaching the service requires a manual `kubectl port-forward` in a second terminal.

**Impact:** An engineer running `sun status` sees running pods but no port-forward hint, and must know kubectl to reach their own service.

**Remediation:** Fix `cmd_status.ml` to query `ClusterIP` services. Have `sun up` automatically start port-forwards in the background (same pattern as `sun dev up`) and print the localhost URL directly.
