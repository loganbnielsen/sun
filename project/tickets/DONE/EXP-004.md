`sun cloud init` command is missing.

**Description:** `sun cloud init` does not exist. Terraform modules exist in `platform/infra/aws/` and `platform/infra/gcp/` but require running `terraform` directly with no documentation on how to use them.

**Impact:** After validating locally, an engineer wanting to deploy to a real cloud environment must learn Terraform, VPC networking, and IAM configuration — all things the platform promises to abstract.

**Remediation:** Implement `sun cloud init --aws` / `sun cloud init --gcp` wrapping `terraform init && terraform apply`, printing provisioned endpoints on completion. Add prerequisites note (terraform binary, cloud credentials) to README. All `dir` values interpolated into shell commands must use `Filename.quote`.

**Note:** Previously reviewed and passed (worktree `../sun-EXP-004-cloud-init`), but changes were never merged to main. Worktree is gone. Implement from scratch.
