vendor/ symlinks and SUN_HOME not documented; binary cp path causes silent dune build failure.

**Depends on:** None.

**Description:** `sun new workspace` creates `vendor/framework` and `vendor/integrations` as symlinks pointing into the Sun checkout. The checkout is inferred from the binary path via `/proc/self/exe` (`infer_sun_home()` in `sun_cli_cmd_new.ml`). If inference fails — e.g., because the binary was copied to `/usr/local/bin/sun` as TUTORIAL.md instructs (`cp _build/default/cli/sun/bin/main.exe /usr/local/bin/sun`) — the workspace is created without `vendor/` links. The CLI prints a NOTE, but then exits normally. `dune build` subsequently fails with "Library not found: sun_svc" (or similar). Neither README.md nor TUTORIAL.md mentions vendor links or `SUN_HOME`.

**Impact:** An engineer who follows TUTORIAL.md's installation instruction (`cp ... /usr/local/bin/sun`) will scaffold a workspace that immediately fails `dune build` with a cryptic error. There is no documented diagnosis or fix path. The engineer must read the CLI NOTE output (which appears only if they look back at the `sun new workspace` output), read `sun_cli_cmd_new.ml`, or discover `SUN_HOME` independently.

**Remediation:**
1. **README.md Quickstart install instruction (line 166):** Change `cp _build/default/cli/sun/bin/main.exe /usr/local/bin/sun` to `ln -sf "$(pwd)/_build/default/cli/sun/bin/main.exe" ~/.local/bin/sun` so the binary remains inside the checkout and `infer_sun_home()` resolves correctly. (The Quickstart already uses `ln -sf` for the symlink pattern — make TUTORIAL.md consistent.)
2. **TUTORIAL.md Part 2:** Add a note after the `sun new workspace` command explaining that the generated workspace links Sun framework source via `vendor/framework` and `vendor/integrations`. State that these links point into the Sun checkout that the binary was run from, and that if the binary was moved or `SUN_HOME` is not set, the user can fix this with: `export SUN_HOME=/path/to/sun && ln -sf $SUN_HOME/framework <workspace>/vendor/framework && ln -sf $SUN_HOME/integrations <workspace>/vendor/integrations`.
3. **`sun_cli_cmd_new.ml` `new_workspace` function:** Upgrade the NOTE to a warning that includes a direct recovery command, and consider printing it before "Done" so it is not buried at the end of the output.
