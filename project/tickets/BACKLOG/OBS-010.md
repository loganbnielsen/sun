Add `sun open` command (logs/metrics/dashboard)

**Depends on:** None.

## Problem

`sun logs` already prints a copyable Grafana Explore URL before streaming
(`Sun_cli_logs.grafana_explore_url`, FEAT-023), but there's no standalone
way to jump straight to Grafana for metrics or the workspace dashboard —
`docs/architecture/observability-design.md`'s `sun open logs|metrics|dashboard`
commands don't exist yet.

## Goal

A `sun open` command that opens (or prints, non-interactively) the right
Grafana view at workspace, domain, or service scope, reusing the URL-building
already proven in `Sun_cli_logs`.

## Acceptance criteria

- `sun open logs [domain[/service]]`, `sun open metrics [domain[/service]]`,
  `sun open dashboard [domain[/service]]` all work; omitting the scope opens
  the workspace-level view.
- Default behavior prints the URL and attempts to open it in the user's
  browser (best-effort; never fails the command if no browser is available
  in the environment — print the URL either way).
- `--links` (or equivalent flag) prints the raw URL only, no browser-open
  attempt — for scripting/copy-paste, matching the doc's example.
- Metrics/dashboard URL-building follows the same pattern as
  `Sun_cli_logs.grafana_explore_url` (base URL override flag, same
  namespace/label-selector conventions).
- Tests cover URL construction at all three scopes without requiring a live
  Grafana instance.
