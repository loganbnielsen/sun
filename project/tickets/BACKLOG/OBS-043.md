Wire a PagerDuty receiver into Alertmanager so `SunHighErrorRate`/`SunPodRestartLoop` actually notify somewhere.

**Depends on:** None.

## Problem

OBS-040 shipped Alertmanager with a `null` receiver by default (deliberately
— no external service to assume). Alerts fire and are visible in
Alertmanager's own UI/API only; nothing pages or texts anyone. That makes
the alerting feature hard to demo end-to-end, and leaves every real user
with the same gap.

## Goal

Give the demo (and any real user) a working example of an Alertmanager
receiver that actually notifies a human, using PagerDuty's free tier (up
to 5 responders, 100 SMS/month, no cost) as the reference integration.
PagerDuty specifically because its free plan is functional and not being
sunset — Opsgenie was considered and rejected: Atlassian is retiring it
(no longer sold since March 2025, support ends April 2027).

## Remediation

1. Extend `local.prometheus_alertmanager_config` in
   `platform/infra/base/main.tf` with a `pagerduty_configs` receiver
   entry, per `helm show values prometheus-community/alertmanager
   --version 1.10.0`'s receiver shape.
2. Route needs a routing/integration key — source it from a Terraform
   variable (e.g. `var.pagerduty_integration_key`), not hardcoded,
   defaulting to unset so the existing `null`-receiver behavior is
   unchanged unless a user opts in.
3. Document the setup step (creating a PagerDuty "Events API v2"
   integration, obtaining the integration key) in
   `docs/deployment/observability-backends.md`'s existing "wire up a real
   receiver" section (~lines 196-235).
4. Validate with `terraform validate`/`terraform fmt -check`.

## Acceptance criteria

- With `pagerduty_integration_key` set, a firing `SunHighErrorRate` or
  `SunPodRestartLoop` alert creates a PagerDuty incident (and, if the
  PagerDuty account's notification rules are configured for SMS, texts a
  responder).
- With the variable unset, behavior is unchanged from today (`null`
  receiver, no external calls).
- `docs/deployment/observability-backends.md` documents the setup steps.
