Add `sun status` Kubernetes rollout diagnosis

**Depends on:** None.

## Problem

When a deploy fails before the app starts, Loki may have no useful app logs.
The useful facts are in Kubernetes: rollout state, pod phase, container waiting
reason, restart reason, and recent events.

## Goal

Make `sun status` explain failed deploys directly from Kubernetes state.

## Acceptance criteria

- `sun status` reports deployment/rollout health for Sun services in the active
  target cluster.
- Failed pods show phase, container state/reason, restart count, and image.
- Pending pods include recent scheduling events.
- Image pull failures include recent `FailedPull`, `ErrImagePull`, and
  `ImagePullBackOff` events.
- Crash loops include last termination reason when Kubernetes exposes it.
- The command works when Loki is absent or unhealthy.
- Tests cover parsing/summarizing representative Kubernetes JSON fixtures.
