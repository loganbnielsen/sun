# SEC-001: Hardcoded dev credential in live Kubernetes Secret

**Depends on:** None.

## Summary

`sun up` and `sun deploy` (without `--emit-to`) bake a hardcoded dev password into every
Kubernetes Secret they apply. The credential originates in `default_secrets` in
`cli/sun/lib/sun_cli_manifest.ml`:

```ocaml
(* sun_cli_manifest.ml line 119 *)
let default_secrets = [
  "POSTGRES_URL", "postgresql://postgres:dev@postgresql.postgresql.svc.cluster.local:5432/dev";
]
```

When `Kubernetes_live` mode is active (the default for `sun up` and `sun deploy` without
`--emit-to`), `secret_doc` emits this value verbatim in `stringData:`. An operator who
runs `sun up` against a production cluster without knowing to override `POSTGRES_URL`
deploys with the weak well-known password `dev`.

## Affected code

- `cli/sun/lib/sun_cli_manifest.ml` — `default_secrets` constant (line 119)
- `cli/sun/lib/sun_cli_deployment_plan.ml` — `render_spec`, `Kubernetes_live` branch
  (line 363–365)

## Remediation

Replace the hardcoded password in `default_secrets` with an empty string:

```ocaml
let default_secrets = [
  "POSTGRES_URL", "";
]
```

Add a pre-flight check in `cmd_up.ml` (and optionally in `cmd_deploy.ml`) that reads
`POSTGRES_URL` from the environment and fails with a clear error message if it is not
set and the target is not a local dev cluster. The check should be performed before any
`kubectl apply` is issued.

Alternative: gate `Kubernetes_live` manifest emission so that secret values must be
supplied via environment variables, rejecting any empty default.

## Acceptance criteria

- `sun deploy --dry-run` output contains `POSTGRES_URL: ""` when `POSTGRES_URL` is not set
  in the environment.
- `sun up` emits an actionable error and exits non-zero if `POSTGRES_URL` is unset and
  the cluster is not a known local dev cluster.
- The value `postgresql://postgres:dev@` no longer appears in any live-mode manifest output.
- Existing tests in `cli/sun/test/test_manifest_render.ml` that assert the presence of the
  dev URL must be updated to assert the empty-string default.
