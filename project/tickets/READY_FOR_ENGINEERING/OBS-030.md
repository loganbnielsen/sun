Local observability dashboards and metrics reachability are not wired

**Depends on:** None.

## Problem

`sun open dashboard` points at the Grafana dashboards provisioned by
`platform/infra/base`, but `sun dev up` only installs `grafana/loki-stack`; it
does not install the Sun dashboard ConfigMaps or the Prometheus datasource
ConfigMap. Local Grafana can be reachable while the Sun dashboard URLs are
missing.

`sun status` also checks local Prometheus at `http://localhost:9090/-/healthy`,
but `sun dev up` only forwards Pushgateway on `9091`, not the Prometheus server
on `9090`.

## Goal

The local dev substrate should match the CLI contract:

- `sun open dashboard` resolves to dashboards that exist in local Grafana.
- `sun status` can probe local Prometheus at `localhost:9090`.
- Existing local Loki, Grafana, and Pushgateway behavior keeps working.

## Remediation

1. Enable Grafana sidecar dashboard and datasource loading in the local
   `grafana/loki-stack` install.
2. Apply local ConfigMaps for the existing Sun dashboards and Prometheus
   datasource after Grafana is installed.
3. Start a Prometheus server port-forward on `localhost:9090`.
4. Add focused tests for any pure rendering/argv helpers introduced.
