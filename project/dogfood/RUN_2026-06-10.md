## Findings

**`infer_sun_home` works in containers.**
`/proc/self/exe` resolves correctly inside Docker. Ancestor walk from
`/sun/_build/default/cli/sun/bin/` reaches `/sun`, passes `is_sun_home` check,
and vendor links are created pointing at `/sun/framework` and
`/sun/integrations`. No `SUN_HOME` override needed when the binary lives inside
the checkout.

**`libpq5` is a runtime dep of the `sun` binary, not just a build dep.**
The binary links against `libpq.so.5` directly. Running `sun --help` before
`libpq5` is installed fails with a dynamic linker error. The prerequisites
section now documents this explicitly.

**Prerequisites section is complete.**
No package was found missing. Installing exactly the apt and opam packages
listed in `docs/dogfood/DOGFOOD.md` is sufficient to get from zero to a passing
`dune build` on Ubuntu 24.04 + OCaml 5.4.1.

**`dune build` timing is warm.**
The 2-second build reused compiled artifacts from the host's `_build` directory
(the Sun repo was mounted read-only including its `_build`). A cold build (no
prior `_build`) would be longer — not yet measured.
