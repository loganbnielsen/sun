## Friction Log

**Step:** Step 2 — `dune build` on generated workspace  
**Command:** `eval $(opam env) && dune build`  
**Expected:** The generated workspace compiles without errors.  
**Actual:**
```
File "app/comms/notify_worker/bin/main.ml", line 2, characters 21-34:
2 |   let postgres_url = Option.filter (fun s -> s <> "") (Sys.getenv_opt "POSTGRES_URL") in
                         ^^^^^^^^^^^^^
Error: Unbound value Option.filter
Hint:   Did you mean Option.iter?
File "app/payments/charge_svc/bin/main.ml", line 2, characters 21-34:
2 |   let postgres_url = Option.filter (fun s -> s <> "") (Sys.getenv_opt "POSTGRES_URL") in
                         ^^^^^^^^^^^^^
Error: Unbound value Option.filter
```
The DOGFOOD-010 fix added `Option.filter` to the generated service/worker entrypoint templates in `cli/sun/lib/sun_cli_cmd_new.ml` to strip empty `POSTGRES_URL` values. `Option.filter` does not exist in the OCaml standard library (confirmed: OCaml 5.4.1). The correct idiom is `Option.bind ... (fun s -> if s = "" then None else Some s)` or a `match` expression.  
**Time lost:** Immediate blocker — fresh workspace does not build.  
**Workaround:** None short of patching the generated files by hand.  
**Blocks two-minute claim?** yes  
**Suggested fix:** Replace `Option.filter (fun s -> s <> "") ...` in the `sun_cli_cmd_new.ml` templates with `Option.bind (Sys.getenv_opt "POSTGRES_URL") (fun s -> if s = "" then None else Some s)`.
