## Friction Log

### Friction 1: `sun dev up` prints ~50 lines of noisy Helm NOTES and deprecation warnings

**Step:** Step 3 — `sun dev up`
**Command:** `sun dev up`
**Expected:** Structured Sun output confirming each infra service installed; operator-visible signal only.
**Actual:** Two categories of noisy output surfaced:
  1. `grafana/loki-stack` prints `WARNING: This chart is deprecated` — the chart is marked `deprecated: true` in its Chart.yaml metadata. The chart still installs, but a first-time user sees an alarming warning with no explanation or remediation hint.
  2. Bitnami PostgreSQL prints a ~30-line `NOTES:` block including a prominent paid-tier notice: _"Since August 28th, 2025, only a limited subset of images/charts are available for free. Subscribe to Bitnami Secure Images to receive continued support and security updates."_ This is a marketing message (the chart still works), but it reads as a hard requirement to a new user. Additional noise includes rolling-tag warnings and resource-limit advisories.
**Time lost:** 0 minutes (did not block progress), but approximately 1-2 minutes of confusion for a first-time user parsing the wall of text.
**Workaround:** Read carefully, ignore, continue.
**Blocks two-minute claim?** no
**Recurs across runs?** yes — identical warnings observed in `RUN_2026-06-10-full.md` (2026-06-10). This is the third occurrence across run history.
**Suggested fix:** In `cli/sun/bin/cmd_dev.ml`, capture `helm upgrade --install` stdout/stderr and filter before printing. Suppress `NOTES:` blocks and bare `WARNING:` lines from chart output; emit only Sun's own structured status line (`Installing Loki... ✓`). The deprecation of `loki-stack` also warrants migrating to the Grafana `grafana/grafana` + `grafana/loki` chart split used in the current Grafana Helm chart ecosystem.
